# Финансовый анализатор
Описание проекта
Проект представляет собой систему для анализа финансовых операций и формирования отчётов. Система позволяет загружать данные из Excel‑файлов, проводить анализ транзакций и формировать различные отчёты.

## Структура проекта
src/ — основной код проекта
reports.py — модули для формирования отчётов
services.py — сервисные функции
utils.py — вспомогательные функции
views.py — формирование выходных данных
tests/ — тесты проекта
requirements.txt — зависимости проекта


## Установка

# Клонирование репозитория
git clone https://github.com/your-repo.git

# Установка зависимостей
pip install -r requirements.txt


## Запуск основного скрипта
python main.py

## Основные возможности
### Отчёт по категориям расходов — анализ трат по категориям за последние 90 дней
### Инвесткопилка — расчёт накоплений по заданному порогу
### Поиск транзакций — простой поиск по описанию операций
### Загрузка данных — импорт из Excel‑файлов с проверкой корректности данных
