# Coursework_1

Курсовая работа: обработка банковских транзакций, формирование отчётов и аналитика расходов.  
Реализовано на **Python 3.12** с использованием **Poetry** для управления зависимостями.

## 🚀 Быстрый старт

### 1. Установка зависимостей

Проект использует **Poetry**. Убедитесь, что он установлен, затем выполните:

```bash
cd Coursework_1
poetry install

## Активация окружения
Poetry автоматически активирует окружение при запуске команд через
Windows (PowerShell): poetry shell
macOS / Linux: poetry shell

## Запуск проекта
Точка входа — src/main.py. Запуск через Poetry: poetry run python -m src.main

Или, если активировано окружение: python -m src.main
